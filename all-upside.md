# 只赚不赔 

有人总结数学研究的特点：成功了能很快得到验证成为颠扑不破的成果，失败了却几乎不用承担成本之外的责任，错误没有直接的严重后果。

可以发现，ai尤其是llm领域恰好也符合这个标准。

这样的好事要多做。关键问题是有多少这样的事？

容易想到的有让ai探索不同的学习机制和架构，优化各种算法/数据结构/硬件，对已有数学进行压缩等。

# All Upside
Some have described a distinctive feature of mathematical research: success can be quickly verified and yields an indisputable result, while failure has almost no consequences beyond the resources spent, and mistakes cause no direct, serious harm.

AI research, especially work on LLMs, fits this description as well.

We should do more of this. The key question is: how many such opportunities are there?

Some obvious examples include using AI to explore different learning mechanisms and architectures, optimize algorithms, data structures, and hardware, and compress existing mathematics.
